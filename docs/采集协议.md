# 采集协议 v1

独立端口仅提供 GET /api/v1/metrics，要求 HTTPS、配对指纹及 Authorization: Bearer 凭据。该接口不提供配置、密钥、配对码或管理操作。

顶层包括 schema_version=1、version、observed_at（RFC3339 UTC）、hostname、platform、capabilities；指标数组／对象为 cpu、memory、gpus、disks、volumes、disk_io、network、sensors、uptime。

可选数值示例：

    {"value":null,"unit":"°C","status":"unavailable","reason":"未找到 CPU 温度传感器"}

成功数值为 status=ok。字节 B、速率 B/s、温度 °C、利用率 %、运行时长秒。存储空间和磁盘为独立数组，不能假设数量一致。磁盘包括内置／外接、型号、接口、容量、温度、健康及 checked_at；序列号不下发。

只接受明确私有／回环 IP 端点，不跟随重定向，不连接 DNS 名称。TLS 配对使用 SHA256 指纹并检查证书有效期；撤销凭据或更换证书后需要重新配对。

接口设超时和响应大小限制。无效协议、采样时间明显超前和过旧快照分别拒绝或显示采集异常。主端每 15 秒读取；三次连接失败离线，重试最长两分钟；成功后恢复正常间隔。

GET /api/v1/display 不包含采集凭据。NAS 状态为 online、connecting、offline、auth、stale、error、pending。非 online 时概览不显示旧快照的实时值；查看历史需进入独立带标识的页面，不参与轮播。
