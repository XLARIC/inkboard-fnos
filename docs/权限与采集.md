# 权限与采集边界

权限声明请求 root 生命周期，专用用户／组为 inkboard-fnos。原因是普通用户不能保证读取 ATA SMART、Intel PMU、部分传感器及全部存储卷统计。

| 进程 | 身份 | 行为 |
|---|---|---|
| 网页与 HTTPS 采集接口 | 专用应用用户 | 读取快照；天气请求；保存私密配置与缓存；局域网页面和只读接口 |
| 硬件助手 | root | 指定 proc/sys 统计；仅对 /volN 做文件系统统计；固定的只读硬件工具；写固定运行目录快照 |

助手无网络监听、不接收远端命令、不读取网页请求、不遍历用户文件。/run/inkboard-fnos 由 root 管理、权限 2750；快照为 root 所有、应用组只读的 0640 文件。停止进程前检查真实执行程序，避免误杀复用的 PID。

CPU、网络、磁盘采用两个计数差和实际间隔；计数器复位后等待新采样。内存为 MemTotal−MemAvailable。

物理磁盘排除分区、dm、md、loop 等虚拟聚合，保留系统、外接、未分配磁盘。存储空间只统计独立 /volN 挂载，排除子目录和重复挂载；RAID 可用容量不能由成员盘简单相加。

Intel 显示最繁忙引擎使用率，不将多个引擎相加。AMD 优先 sysfs；NVIDIA 使用只读 nvidia-smi。缺少驱动、共享显存或传感器时不推算虚假数值。

ATA 每五分钟最多查询一次，明确设备类型且使用 smartctl -n standby，休眠或不支持检测即跳过。USB／SCSI 桥接不主动自动识别。NVMe hwmon 仅在运行状态明确 active 时低频读取；全局扫描排除 nvme／drivetemp。缓存温度带检查时间。

仍需实机核对多盘、多挂载、USB 桥接、Intel UHD Graphics、磁盘休眠、权限、用户创建及升级／卸载数据保留。隔离容器通过不等于 fnOS 实机通过。

默认主端没有 NAS，硬件助手在本机采集未启用时不采样。管理页显式添加本机后开始采样；仅采集器角色自动采样。安装脚本仅在用户终端交互执行，通过官方 appcenter-cli 安装，密码只进入权限 0600 的临时环境文件，退出时删除，不发送到主端或 GitHub。
