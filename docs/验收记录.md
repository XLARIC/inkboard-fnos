# InkBoard 验收记录

日期：2026-10-02。状态为可安装预览版；模拟测试不能替代实机验收。

## 0.1.0-alpha.7：底部导航栏避让与内容高度

- 用户 Voyage 实拍证实 alpha.6 仍有日期、体感、日出日落、GPU 显存、内存容量及更新时间被区块裁切。浏览器固定底栏不能由网页隐藏，而页面此前按整个视口和固定百分比划分区块。实际旧 WebKit 字高和模拟浏览器不同；上一版模拟通过不代表真机通过。
- `/basic` 默认扣除 64 像素底部空间，取 `innerHeight` 与可用时的 `visualViewport.height` 较小值。通知也放在扣除底栏后的区域。天气屏按钮循环 0／48／64／80／96／120，设备页支持 0–200，链接 `bottom` 参数支持同范围；保存仅影响本机浏览器。网页无法自动获知覆盖它的 Kindle 原生导航栏精确高度，64 是默认值，可由用户微调。
- CSS 2／ES5 轻量布局改为测量自然内容高度，再分配剩余空间；有限的紧凑排版及分时／多日并列用于较矮视口。GPU、时钟和存储空间在足够时直接排列，只有实际不足时横向浏览，避免拿横向滚动掩盖纵向裁切。窄运行时间可换行。
- 标准字号 17 个尺寸（包含 600×700、600×640、800×500）× 黑白／彩色 × 天气／在线 NAS／离线 NAS，共 102 个场景。黑白全部预留 64，彩色预留 0。逐个文字叶节点核对横纵边界，允许的横向轨道只排除横向裁切，不排除纵向裁切；未发现区块越界或文字裁切。另测 600×800 下 0／48／64／80／96／120 × 三屏，共 18 个场景。记录见 [布局检查](layout-alpha7.json)。仅合成数据，不能替代实机。
- 天气屏实际浏览器点击留白按钮，通过全周期调节；点击当前天气后局部同步计数增至 1，留白与页面保持。设备页保存 96 后进入黑白看板，刷新页面仍为 96；验证后恢复测试默认 64。600×800 独立 iframe 的截图为 [黑白天气](screenshots/voyage-weather-alpha7.jpg)和 [黑白 NAS](screenshots/voyage-nas-alpha7.jpg)，底部空白为导航栏预留，不含用户地址或真实硬件快照。浏览器整体尺寸覆盖未实际应用，未将它作为尺寸证据。
- Go 竞态测试和静态检查通过；官方 fnpack 已生成 amd64／arm64 FPK。程序 alpha.7，FPK 0.1.6。Voyage 导航栏实际高度、旧 WebKit 度量和实体按键仍需升级后真机核对；保留此前未通过的实机项目。

## 0.1.0-alpha.6：Voyage 排版修正

- 用户 Kindle Voyage 实拍证实 alpha.5 存在日期／小时文字裁切及不必要的横向布局；此前只检查容器溢出的模拟结果不足以发现嵌套文字裁切，不能作为实机通过依据。
- 原因：看板同时加载旧页面样式，旧最小卡片高度和边距与绝对区块／横向轨道尺寸冲突；所有指标被统一设为横向排列，滚动条又占用内容高度。
- 使用独立看板 CSS，固定 CPU／内存／CPU 温度／运行时间布局、纵向 GPU 字段；型号可换行，长缺失原因与完整地址可通过说明查看。列表按真实可用宽高判断是否横向展示。
- 最终构建标准字号共 54 个场景：彩色 14 个既定横竖屏尺寸 × 天气／在线 NAS／离线 NAS；轻量 `/basic` 600×800、800×600、320×568、568×320 × 三屏。逐个文字叶节点核对区块及列表可视区域，排除允许的横向浏览，未发现纵向文字裁切或区块越界。结果为 [布局检查记录](layout-alpha6.json)，只使用合成数据。
- 600×800 的两个入口中，三地时钟、CPU 指标、单 GPU、三个存储空间直接显示；五块物理磁盘与两个网卡列表按真实溢出横向展示。800×600 中网卡也能直接显示。
- 实际网页操作：分时列表 ArrowRight 浏览至 120px，点击“当前天气”后同步计数从 0 增至 1，位置仍为 120px；“说明”按钮显示完整缺失原因。彩色 NAS 屏同步计数由 1 增至 4 后，仍停留在同一 NAS 主屏。
- 合成预览截图：[Kindle 天气](screenshots/voyage-weather-alpha6.jpg)、[Kindle NAS](screenshots/voyage-nas-alpha6.jpg)。不包含用户地址或真实设备快照。
- Go 竞态检测与静态检查通过；既有概览与路由测试再次通过。官方 fnpack 1.2.3 生成 amd64／arm64 FPK；程序 alpha.6，manifest 0.1.5。样式与脚本按程序版本更新 URL，减少旧浏览器升级后误用缓存。
- 公开标签为 087de8c；[Test and package](https://github.com/XLARIC/inkboard-fnos/actions/runs/36950084375) 与 [Versioned release](https://github.com/XLARIC/inkboard-fnos/actions/runs/36950086314) 均成功，包含 Debian 安装生命周期与多架构镜像构建。两种 FPK 匿名重新下载，与公开 SHA256SUMS 一致；GHCR 匿名清单返回 200，含 linux/amd64 与 linux/arm64。未在本机重复 Docker 客户端拉取。
- Kindle Voyage 实体按键、旧 WebKit 行为、浏览器栏占用高度、触摸、实机字号与长时间显示仍需升级后核对。模拟浏览器不等于 Voyage 实机验收。
