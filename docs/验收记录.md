- 新增概览结构、完整小时日期和缓存不被选择状态修改的回归测试。竞态测试与静态检查通过。

- 实际网页验证日期选择、小时详情、鼠标拖动和 PageDown 翻屏；定时同步从计数 2 增至 4 后，仍停留在同一 NAS；返回天气后日期／小时选择和横向位置 707.5px 保持不变。触摸与实体 PagePress 仍需实机验收。截图为合成数据：[天气](screenshots/one-screen-weather.jpg)、[NAS](screenshots/one-screen-nas.jpg)、[黑白](screenshots/one-screen-kindle.jpg)。
- 本版 /basic 使用 ES5 脚本与 CSS 2 布局，取消 meta refresh。下方旧版“无脚本／自动子分页”的记录只代表历史版本，已被本版替代。
- 首次原生飞牛 x86 安装及入口检查于 2026-10-01 完成：主端、管理／黑白／彩色／设备／采集器脚本／健康接口均返回 200，默认零台 NAS。系统版本范围与重启自启动、真实硬件读取未因此视为通过。
