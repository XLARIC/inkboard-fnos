# 0.1.0-alpha.1 验收记录

日期：2026-10-01。状态为可安装预览版；模拟测试不能替代实机验收。

## 已通过

- Go 1.27.1：16 项测试（包含单独开启的真实天气集成），竞态检测及静态检查。
- 配置原子保存、回滚、重启恢复、凭据加密；默认没有 NAS；时钟列表增删、排序和空列表持久化。
- 私有网段、DNS 重绑定限制、管理登录、跨站请求校验；TLS 指纹、凭据校验及指标协议检查。
- 昨天 + 今天 + 未来 15 天；天气空值；跨日期、夏令时、分数时差、23／25 小时天气日。
- Open-Meteo 实际测试：公开奥克兰测试坐标，17 个日期、408 条小时数据；坐标对应时区查询正常。未使用用户定位。
- 物理磁盘与分区／虚拟块设备分开；计数器首样本和重置；离线历史标识、三次网络失败与重连恢复；认证、证书及采集异常分类。
- 原生 FPK：官方 fnpack 1.2.3，分别生成 x86（amd64）和 ARM（arm64），包含许可。
- Debian ARM64 隔离容器内：安装、默认不采集、启停与状态、普通用户网页、root 助手只读快照、配置、角色切换、升级备份与自定义端口、卸载保留文件。
- Docker ARM64 本地构建。非特权、只读根目录、撤销 capabilities 的纯天气容器运行验证。
- 两种入口二维码实际通过 Apple Vision QR 解码，得到对应的完整链接；无外部二维码请求。详细地址保存和重启持久化，地址服务默认关闭、解析、缓存及频率限制。
- 电脑端彩色管理界面、时钟添加／排序／删除实际网页流程，设备显示偏好和预览。管理页在窄屏无页面横向滚动。

Kindle 无脚本入口，600×800：首屏含城市时间与当前天气，高度 770px。8 页天气、11 页在线 NAS、2 页离线 NAS 的全部概览无横向滚动且均在 800px 内。脚本元素数量为 0。新增详细地址后的实际测试天气首屏为 762px，无横向滚动。完整小时详情另行每页 2 小时；少行模式可进一步拆页。
