InkBoard 0.1.0-alpha.2 预览版：局域网天气、可配置城市时钟、Kindle 无脚本入口、飞牛 NAS 监控。

- Kindle 独立黑白无脚本入口；手机／iPad／PC 使用深蓝和青色彩色界面，横竖屏自动分页。管理与设备页提供二维码、完整链接、复制和直接打开。
- 新增免 Key 地图选点弹窗：打开 Google Maps 搜索、粘贴坐标／完整链接、预览确认后填入；可在支持的浏览器获取当前位置。分享短链接、视图中心和无法唯一确定地点的链接有明确提示。无需 Google API Key，也不调用收费地址 API。
- 经纬度保留原始小数精度，定位不再按约 1 公里取整；预览显示 8 位小数，并显示设备报告的定位误差范围。
- 支持详细地址手动设置，以及可选自建或授权 Nominatim 服务查询坐标；默认不向公共地址服务发送查询。
- 默认纯天气，NAS 在受保护的电脑端管理页添加。时钟城市支持增删和排序。
- 原生 FPK 分为 amd64（Intel／AMD）和 arm64。同一应用可选择主端或仅采集器；提供交互式采集器安装脚本。
- 物理磁盘与存储空间分别显示，离线指标与历史快照分开。远端采用 TLS、证书指纹和配对凭据。
- 提供 Docker 纯天气运行方式、MIT 源码及第三方许可。

本版已通过自动测试、模拟视口和隔离的生命周期测试。实际飞牛安装、Kindle Voyage、iOS／Android、长时间运行及应用市场审核尚待验收。请先在测试环境使用，详见仓库的验收记录和部署说明。

Docker 镜像提供 linux/amd64 与 linux/arm64。公开注册表匿名协议读取已通过；当前 macOS Docker Desktop 的直接拉取仍返回 denied，暂建议按 README 从源码构建，具体情况见验收记录。
